# RD-152 CI Workflow, Root Scripts, And Docs

## Goal
Make the suite runnable by someone who has not read this file, and run T1 automatically.

## Implementation
`.github/workflows/e2e.yml` (the repo has no workflows yet): Node 22, pnpm 11, `pnpm install --frozen-lockfile`, `pnpm exec playwright install --with-deps chromium`, `pnpm test:e2e` (T1 only — never T2/T3, which touch the network and gas), upload `playwright-report` as an artifact on failure. Root `package.json`: `test:e2e`, `test:e2e:live`, `test:e2e:ui`. New `docs/e2e-testing.md`: the tier table, what each tier needs, how to run one spec, how to read a trace, and the hard rules (never use `.playwright-wallet-profile`, never commit artifacts, never hardcode object IDs, T3 is gated on the user's go-ahead). Add pointers from `README.md` (Build + Test section) and `AGENTS.md` (Environment / Frontend Verification Notes), and one line in `docs/browser-testing.md` distinguishing *exploratory* browser driving via the harness from the *committed* E2E suite — and stating that both use the same `.playwright-wallet-profile/`, so they cannot run at the same time.

**Nix scope.** The repo now ships a flake (`flake.nix`, `nix/`, `docs/nix.md`); CI must keep it from
rotting. Add `.github/workflows/nix.yml`: install Nix (`DeterminateSystems/nix-installer-action`),
run `nix flake check` and `nix develop --command true`. Gate the job on changes to
`flake.nix`/`flake.lock`/`nix/**` — the pinned `sui` tarball is ~1.1 GB, so an ungated job would
re-download it on every push. If it runs often enough to hurt, add a binary cache (Cachix) rather
than dropping the check.

Two traps to document in `docs/nix.md` while here:

- **`packageManager` must track the nixpkgs `pnpm`.** pnpm 10+ has `manage-package-manager-versions`
  on by default: if `package.json` names a different version than the `pnpm` on `PATH`, pnpm ignores
  the Nix binary and downloads the named version into `~/.local/share/pnpm/.tools/`, silently
  defeating the pin and requiring network on first use. On any `nix flake update`, re-check
  `nix eval nixpkgs#pnpm.version` and sync `packageManager`. (This already bit once and is fixed at
  11.17.0.) Consider asserting it in the nix workflow so drift fails CI instead of going unnoticed.
- **`playwright install --with-deps` is correct on the `ubuntu-latest` runner and wrong on NixOS.**
  `--with-deps` shells out to `apt-get`. Locally in the devShell use `pnpm exec playwright install
  chromium` with no `--with-deps`; nix-ld (`NIX_LD`/`NIX_LD_LIBRARY_PATH`, set by the devShell,
  requires `programs.nix-ld.enable = true` on the host) supplies the browser's shared libraries.

Set the `nix flake update` cadence explicitly in `docs/nix.md` — on demand plus a stated review
interval — so the input does not silently age.
