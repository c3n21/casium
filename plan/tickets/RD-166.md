# RD-166 E2E Coverage — Agent Card And Mismatch Denial (stretch)

## Goal
Regression-guard the two behaviors this epic introduces, at the tier each one can actually be tested in.

## Implementation
Follow `plan/epics/E.md`'s tier model — do not re-derive it. **T1 (`stubbed`)**: extend RD-144's `agentApi.ts` fixture with `GET /identity` and add `specs/mandate-identity.spec.ts` asserting the card renders both truncated addresses, that no free-text address input exists by default, that an agent-offline stub disables submit with the reason, and that `agentEvmAddress: null` does the same. Add the `/identity` shape to RD-149's drift guard so the stub cannot rot away from the real agent response.
