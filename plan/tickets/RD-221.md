# RD-221 Use the shared municipality constants everywhere

## Goal
Delete the two hand-typed municipality tables in the web app and read the canonical one
from `@casium/shared`, so the lists cannot disagree again.

## Context
- `packages/shared/src/constants.ts` already exports `MUNICIPALITIES` **and**
  `MUNICIPALITY_LABELS`. It is canonical, and nothing in `apps/web` imports it.
- There are **four** copies under `apps/web`, not two (corrected 2026-07-31 after audit):
  `MandateForm.tsx:17` (five entries, omits code 6), `renter/page.tsx:47`
  (`6: "Porto (ineligible)"`), `ListingForm.tsx:15` and `provider/page.tsx:17`
  (both `6: "Porto (ineligible demo)"`).
- The shared constant labels code 6 plain `"Porto"`. All five disagree today.
- `provider-dashboard.spec.ts:24` asserts the listings row contains
  `"Porto (ineligible demo)"`, so that suffix must survive as a derived render-site label
  or the stubbed tier goes red.
- `spec/development-spec.md` §4.1 duplicates the same table a fourth time — RD-200 removes it.

## Steps
1. Import `MUNICIPALITIES` and `MUNICIPALITY_LABELS` from `@casium/shared` in both files.
2. Delete the two local table literals.
3. Derive the mandate form's selectable options from the shared map. Decide explicitly
   whether code 6 is selectable — it is the deliberately-ineligible demo municipality, so
   it should be listed where listings are shown but **not** offered as a mandate option.
4. If the `"(ineligible)"` suffix is worth keeping in the UI, add it at the render site as
   a derived label. Do not fork the constant to carry presentation text.

## Constraints
- Do not change the values in `packages/shared` — the codes are on-chain data and Move
  tests depend on them.

## Done when
- [ ] No municipality code or label literal remains under `apps/web`.
- [ ] The renter page and the mandate form show the same label for every code they share.
- [ ] Code 6 is visible where listings are shown and unavailable as a mandate target.
- [ ] `pnpm --filter @casium/web typecheck` passes.

## Verify
- **Tests.** Extend `apps/web/src/components/MandateForm.test.ts` to assert the options come
  from the shared constant and that code 6 is not among them.
- **Evidence to capture.** A grep showing zero municipality literals under `apps/web`.

## Notes
- **Demo impact.** Low visually, but this is the drift that made two pages disagree about
  which municipalities exist.
