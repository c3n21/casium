# RD-220 Update Tests, Spec, And Docs For The No-Identity Model

## Goal
Make the repo's contract documents describe the system that now exists, and restore the E2E suite the overhaul breaks.

## Implementation
Two halves. **Tests:** `apps/e2e/specs/renter-packet.spec.ts`, `agent-run.spec.ts`, and `navigation.spec.ts` key off renter-page selectors and packet field names that RD-216 and RD-217 replace; the live tier's `renter-packet.spec.ts` and `landlord.spec.ts` do the same. Rewrite them against the conversation flow, and add a stubbed-tier spec asserting the mandate review card blocks submission until confirmed — that is the epic's central safety property and nothing currently tests it. Update `apps/e2e/src/fixtures/data.ts` to build v2 packets. **Docs:** `spec/development-spec.md` is the implementation contract and specifies the packet shape — update it, and record that the packet no longer carries identity and why. Then `docs/provider-api.md` (packet registration), `docs/seal.md` (what the policy now protects), `docs/demo-script.md` (the renter steps change completely), `README.md` (architecture and the integration table), and `AGENTS.md` (repository structure gains `packages/llm`, status gains this epic). Add `docs/llm.md` covering the adapter interface, the two modes, the grammar-constrained extraction, and — explicitly — that transcription and vision are mocked.

## Done when
- [ ] `pnpm -r test` and `pnpm test:e2e` both pass.
- [ ] No doc describes a packet field that no longer exists.
- [ ] `docs/llm.md` states the mock status of transcription and vision in its first screen.
- [ ] A reader following `docs/demo-script.md` can run the new renter flow end to end.

## Verify
- **Tests.** The suite itself.
- **Evidence to capture.** Full `pnpm -r --if-present build`, `pnpm -r --if-present test`, and `pnpm test:e2e` output.

## Notes
- **Failure fallback.** None. An epic that leaves the spec describing a deleted schema is not done.
- **Parallel safety.** Owns `apps/e2e/` and the docs. Must land last.
- **Integration.** All — this is the ticket that keeps the claims honest.
- **Demo impact.** Indirect and high: `docs/demo-script.md` is what a walkthrough follows.
