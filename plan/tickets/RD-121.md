# RD-121 Walrus Wallet And Funding Preflight

## Goal
Know, before spending anything, whether the environment can actually store a blob.

## Implementation
Add `pnpm --filter @casium/walrus check:env`, mirroring the existing `@casium/agent check:env`. It should resolve the `walrus` binary (`~/.local/bin/walrus`, never by exporting `PATH`), print the client version and configured context, resolve the wallet address, report SUI and WAL balances, and estimate the cost of storing one packet for the configured epoch count. It must exit non-zero with a readable message when WAL is insufficient, and it must not perform any write.

## Done when
- [ ] The command reports binary version, context, address, SUI balance, WAL balance, and estimated storage cost, and refuses clearly when the wallet cannot pay.
- [ ] Read-only — verified by running it twice with unchanged balances.

## Verify
- **Tests.** Unit tests over captured CLI JSON output for the parsing paths; no live call in CI.
- **Evidence to capture.** Paste the command output with balances redacted to whole numbers.

## Notes
- **Failure fallback.** A documented manual checklist in `docs/walrus-adapter.md`.
- **Parallel safety.** Isolated to `packages/walrus`.
- **Integration.** Walrus.
- **Demo impact.** Prevents a live demo failing on an unfunded wallet.
