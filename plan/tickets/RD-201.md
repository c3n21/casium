# RD-201 Make lint:object-ids pass or record its exemptions

## Goal
Make `pnpm lint:object-ids` exit 0, so the hard rule in `AGENTS.md` is one an agent can obey.

## Context
- `AGENTS.md` → *Hard constraints* states: no address or object-ID literals in app code,
  import from `@casium/contracts-config`, run `pnpm lint:object-ids`. **The check fails at
  HEAD**, and did throughout RD-214/183/221. Every agent has to be told to ignore it, which
  trains agents to ignore a stated hard rule.
- Three findings, all long-standing: `packages/seal/src/config.ts:27` and `:32` (two
  key-server object IDs), and `apps/web/src/components/PacketViewer.tsx:62`
  (`CLOCK_OBJECT_ID`).
- `CLOCK_OBJECT_ID` is the Sui system clock `0x…06` — a protocol constant, not a deployment
  address, so "import it from contracts-config" may be the wrong fix for that one.
- The Seal key-server IDs are network-dependent and arguably belong in `contracts-config`
  alongside the other deployed IDs.

## Steps
1. Decide per finding: move the literal into `@casium/contracts-config`, or exempt it.
2. For anything moved, import it at the use site and confirm no behaviour change.
3. For anything exempted, add an explicit allowlist to `scripts/check-object-ids.mjs` naming
   the file, the constant and the reason — an exemption with no stated reason is a silenced
   check, not a resolved one.
4. Make the script exit non-zero only for genuine violations.

## Constraints
- Do not weaken the check into a warning, and do not exempt by broad glob. A future real
  violation must still fail.
- `packages/seal` has its own consumers; keep it importable exactly as before.

## Done when
- [ ] `pnpm lint:object-ids` exits 0.
- [ ] Every remaining literal is allowlisted with a written reason.
- [ ] Introducing a new hardcoded ID in `apps/web` still fails the check — prove it.
- [ ] `pnpm -r --if-present test` and `pnpm test:e2e` unaffected.

## Verify
- **Tests.** Temporarily add a fake object-ID literal to a web component, show the check goes
  red, then remove it.
- **Evidence to capture.** That red-then-green output, plus the final clean run.
