## Findings that change how the remaining units must be done

- **The named style objects are off-brand.** `MandateForm.tsx:374-392`, `PacketBuilder.tsx:291-292`
  and `app/provider/page.tsx:227-235` use `#2563eb` buttons, `#cbd5e1` borders and `borderRadius: 4`
  — nothing like `globals.css`'s warm paper identity (`#17211d`, `999px`, 22px radius). Porting them
  to the primitives **will legitimately change** how `/renter` and `/provider` look. "Screenshots must
  match" is therefore the wrong gate for U3/U4; it is only the right gate for U1, which changes no JSX.
- **Tailwind preflight is the main risk in U1.** It resets `<p>`/heading margins and unstyles buttons
  and inputs, all of which the current design leans on. U1 must either skip preflight or add a
  compatibility layer, and prove the choice with a before/after screenshot comparison.

## U0 — screenshot harness (commit `f51ace7`)

Adds a `screenshots` Playwright project scoped to its own spec, so `pnpm test:e2e` still selects the
same 25 tests. Usage:

```bash
SHOT_LABEL=before pnpm --filter @casium/e2e e2e:shots   # -> apps/e2e/screenshots/before/*.png
```

Two defects were caught on spot-check and fixed before commit, both worth remembering:

1. **Output must not live under `test-results/`.** Playwright wipes that directory at the start of
   every run, so the first "before" set was destroyed by the very next `pnpm test:e2e`. Output now
   goes to `apps/e2e/screenshots/<label>/`, git-ignored separately.
2. **Screenshots must wait on route-specific content.** Without a wait, all four shots captured the
   pre-paint gradient and three were byte-identical (`40d3446215a1350ea7c53e6ae62e357c`). Each route
   now waits on a testid: `core-message` for `/`, `developer-evidence` for `/renter`,
   `listing-row-listing_lisbon_eligible` for `/provider`, `landlord-page-title` for `/landlord`.
   Note `/renter` cannot wait on `target-checkbox-*` — that only renders once a mandate exists.

Baseline captured and verified to survive a full e2e run — four distinct hashes,
477-568 KB each, `/provider` visually confirmed to show the fully-rendered listings table.

`owns:` was extended (user-authorized) with `apps/e2e/playwright.config.ts`,
`apps/e2e/specs/screenshots.spec.ts` and `apps/e2e/package.json`.
