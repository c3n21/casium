# RD-219 — evidence

Status: **DONE**

2026-07-31. Eight commits, `9b05ddc`..`ec6f952`. Every legacy semantic class is gone from the nine
owned files, and the app is entirely free of inline styles.

## Scope had to be corrected twice

RD-214 landed first and already satisfied two of the three original *Done when* items — no `style={{`
remained and the pages were on utilities. The real remaining work was the legacy semantic classes
RD-214 deliberately kept alive.

The first audit said 49 usages. It was wrong: the regex matched `badge` inside the
`environment-badge` testid and `alert` inside `role="alert"`. **The true count was 29**, and three of
the four components in the original U2 needed no work at all. Match on `className` contents only.

`owns:` grew twice, both user-authorized: `alert.tsx` and `badge.tsx` first (the primitives had no
`success`/`warn`/`error` variants, so full replacement was impossible), then `card.tsx` (its defaults
did not match legacy `.card`, so every call site was going to carry its own geometry override).

## Done-when, against evidence

- **All pages on the primitives.** Zero legacy semantic classes across all nine files, verified with
  a `className`-only grep at the final commit.
- **`pnpm test:e2e` passes with no selector changes** — 25 passed, 0 failed. Every `data-testid` was
  diffed per file against `HEAD` before and after each unit.
- **No `style={{` anywhere under `apps/web`.**
- `node scripts/check-object-ids.mjs` still reports exactly its 3 pre-existing findings.

## What the visual gate caught that code review did not

The agreed bar was *near-identical rendering*. Four defects surfaced only by diffing screenshots
against `apps/e2e/screenshots/after-221/`, and every one would have shipped otherwise:

1. **`Card` forced `text-sm`.** Legacy `.card` set no font-size and inherited 16px, so every migrated
   card silently shrank its contents to 14px. Removing it is what restored `/provider` to
   byte-identical.
2. **`globals.css` keys rules off legacy classes as DESCENDANT selectors**, so removing an ancestor
   class silently drops them, and with Preflight off the fallback is the browser default. Rule 133
   (`.card h2, .card h3, .step-card h2, .step-card h3`) gave headings `margin: 0 0 8px` and
   `letter-spacing: -.025em`; losing it pushed the home page's step-card titles down ~18px and
   reflowed their descriptions. `Card` now applies that treatment centrally; the hand-rolled
   step-card and RoleCard carry it inline. `.table-shell table { min-width: 640px }` had also been
   dropped in `MandateStatus`. `.pipeline li` was reproduced explicitly on the agent page.
3. **`Card` injects `gap-(--card-spacing)` between top-level children**; legacy `.card` did not, so
   the gap stacked on children that already carried their own margins. Call sites wrap children in a
   single element.
4. **`Alert` was `display: grid`.** Every call site passes loose inline children, which grid
   auto-placed onto separate rows — it split the agent page's "Agent online — 0x371… agentkit: mock"
   banner into three stacked lines. It is now `block`, with grid restored only via `has-[>svg]`,
   which removed five call-site overrides.

Pattern worth carrying: each of these was a **primitive/legacy mismatch best fixed once in the
primitive**, not at call sites. Where that was done late, call sites had already accumulated
overrides that then had to be removed.

## The harness is deterministic

Two runs of `e2e:shots` against one build produce byte-identical PNGs on all five routes. This was
tested explicitly, because an agent attributed a real CSS regression to "webfont-loading timing
variance". That explanation is not available here — a screenshot difference is a real change.

## Residual differences, unexplained

- `/` differs from the pre-migration baseline by sub-pixel glyph antialiasing inside the four
  step-cards. Layout, wrap points, heading gaps and card heights all match; canvas dimensions are
  identical. Heading and paragraph text in the same grid column shift in *opposite* directions,
  which argues against a column or gap regression.
- `/agent` differs by a per-channel delta of at most 3/255, confined to the health banner, with
  pixel-identical box coordinates. Ruled out: flake, the grid→block change, `text-align`. Cause not
  isolated.

Neither is visible. Both are recorded rather than explained away.

## Not verified

Only the default no-mandate state of `/agent` was looked at. The other alert states — ineligible,
error, packet-missing, EVM mismatch, multi-target results — are exercised by the e2e suite but have
never been seen. `ListingForm`, `RevokeButton` and `WithdrawButton` gate on a real
`useCurrentAccount()` and remain unrenderable by the stubbed tier; `RevokeButton` and
`WithdrawButton` turned out to need no changes at all.
